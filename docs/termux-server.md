# AI-ассистент через opencode serve в Termux

AI-чат в приложении подключается к настоящей модели через HTTP-сервер
[opencode](https://opencode.ai/docs/server), запущенный на том же телефоне.
Пока сервер запущен — AI работает; когда сервер выключен — приложение
показывает сообщение об ошибке (офлайн-режима нет).

## 1. Установка opencode в Termux

```bash
pkg install nodejs-lts      # или nodejs
npm install -g opencode-ai
opencode upgrade            # держи актуальную версию
```

Войдите в провайдер модели один раз (как обычно работаете с opencode),
например:

```bash
opencode auth login
```

## 2. Агент «tutor» (отвечает только текстом)

Чтобы модель в чате не пыталась редактировать файлы или выполнять команды
в Termux, добавьте агента-наставника в конфиг opencode (глобально):

`~/.config/opencode/opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "agent": {
    "tutor": {
      "description": "Наставник по Python для учеников КодиК: отвечает только текстом",
      "mode": "primary",
      "prompt": "Ты доброжелательный наставник по Python для детей. Отвечай по-русски коротко и понятно. Никогда не используй инструменты и не выполняй команды.",
      "permission": {
        "read": "deny",
        "edit": "deny",
        "bash": "deny",
        "webfetch": "deny",
        "websearch": "deny",
        "glob": "deny",
        "grep": "deny",
        "list": "deny",
        "task": "deny",
        "lsp": "deny",
        "skill": "deny",
        "todowrite": "deny"
      }
    }
  }
}
```

## 3. Запуск сервера

```bash
opencode serve                     # порт 4096, адрес 127.0.0.1
```

Сервер слушает только локальный loopback — другие устройства не получат
к нему доступ. Не биндьте на `0.0.0.0` и не открывайте порт в мобильной сети.

Важно:

- Сервер использует ту же учётку провайдера, что и обычный opencode
  (оплата по тарифу провайдера);
- Продац держите активным, пока пользуетесь AI из приложения.

## 4. Настройка в приложении

1. Откройте вкладку **AI**;
2. Нажмите ⚙️ (настройки);
3. Адрес по умолчанию `http://127.0.0.1:4096`, агент `tutor` — обычно ничего
   менять не нужно;
4. Нажмите **«Проверить соединение»** → появится «Соединение есть»;
5. **«Сохранить и подключить»**.

## 5. Как это работает

- При отправке сообщения приложение зовёт `POST /session` и
  `POST /session/:id/prompt_async`;
- Ответ приходит по SSE (`GET /event`) частями — текст появляется вживую;
- Завершение ответа — событие `session.idle`;
- Если сервер выключен или модель вернула ошибку, в чате появится
  объяснение вместо ответа.

## Диагностика

| Симптом | Причина / решение |
| --- | --- |
| «Сервер не запущен» | Запустите `opencode serve` в Termux и нажмите «Проверить» |
| «Сервер вернул ошибку (401/403)» | Провайдер модели не авторизован: `opencode auth login` |
| Ответ не приходит, «печатает…» долго | Проверьте тариф/лимиты провайдера, либо откройте чат opencode в Termux |
